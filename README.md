# Решатель задач

Сайт для решения уравнений, текстовых задач и задач по физике. Один файл `index.html`, без сборки и сервера.

- Уравнения с одной переменной: быстрый числовой поиск корней прямо в браузере.
- Пошаговые решения: через Claude API, нужен ваш ключ (вводится на странице и хранится в `localStorage` браузера).
- Форматы ответа: только ответ, кратко, подробно, объясни просто.

## Публикация на GitHub Pages

1. Создайте репозиторий на github.com (например, `solver`), публичный.
2. Загрузите `index.html` и `README.md` (кнопка Add file → Upload files).
3. Откройте Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)` → Save.
4. Через 1–2 минуты сайт будет доступен по адресу `https://ВАШ_ЛОГИН.github.io/solver/`.

Свой бесплатный адрес: назовите репозиторий `ВАШ_ЛОГИН.github.io`, тогда сайт откроется по `https://ВАШ_ЛОГИН.github.io/`.

## Важно про ключ API

Ключ каждый посетитель вводит свой собственный, он не хранится в коде. Не вставляйте свой ключ в `index.html` и не публикуйте его в репозитории: любой сможет им пользоваться за ваш счёт.

Модель задаётся в начале скрипта: `var MODEL='claude-sonnet-5-5';`
