# Решатель задач

Сайт для решения уравнений, текстовых задач и задач по физике. Один файл `index.html`, без сборки и сервера.

- Уравнения с одной переменной: быстрый числовой поиск корней прямо в браузере.
- Пошаговые решения: через Claude API, нужен ваш ключ (вводится на странице и хранится в `localStorage` браузера).
- Форматы ответа: только ответ, кратко, подробно, объясни просто.
